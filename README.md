# Modeling and Simulation of Aerospace Vehicles (Zipfel)

## Idea
Workspace for Peter H. Zipfel's CADAC++ simulations (3/5/6-DOF aerospace vehicles) and a unified Python library that re-implements them in Python style, not as a line-for-line C++ transcription.

Mandatory reading: `UPDATES.md`.

## Architecture
**C++ source of truth:** `CADAC_Simulations/` — twelve standalone CADAC++ programs. Each copies executive, `Variable` tables, `Matrix`/`Datadeck`, atmosphere, and I/O. Hierarchy is `Cadac` → `Round3`/`Flat3`/`Round6`/`Flat6` → vehicle (Cruise, Plane, Missile, …). Multi-vehicle runs use a `combus` packet bus.

| Folder | DOF / earth | Vehicles |
|---|---|---|
| HYPER3 | 3DOF round | Cruise |
| AIM5 | 5DOF flat | Aim + Aircraft |
| CRUISE5 | 5DOF round | Cruise + Satellite + Target |
| FALCON5 | 5DOF flat | Plane |
| HYPER5 | 5DOF round | Hyper + Satellite + Target |
| FALCON6 | 6DOF flat | Plane |
| HYPER6 | 6DOF round (+ 3DOF) | Hyper + Radar + Satellite + Ground |
| MAGSIX | 6DOF rotor | Rotor |
| ROCKET6 | 6DOF round | Rocket |
| SAM6 | 6DOF flat (+ 3DOF) | Missile + Aircraft + Rocket + Radar |
| SRAAM6 | 6DOF flat (+ 3DOF) | Missile + Target |
| AGM6 | 6DOF flat (+ 3DOF) | Missile + Aircraft + Target |

**Python target:** `Python/` — installable package `cadac`. Runtime JSONC (scenarios + decks); `cadac.io.translate.deck_asc_to_jsonc` converts CADAC `.asc` decks. Named numpy state; CADAC `integrate` / `look_up` / atmospheres. `run_loop` skips module names missing on a vehicle and seeds combus from store `com_names` before the first execute; plot CSV records vehicle slot 0 only. First slice: kernel + HYPER3 (`CRUISE3`/Round3) + FALCON5 (`PLANE`/Flat3) + FALCON6 (`PLANE6`/Flat6). HYPER5 is runnable from JSONC (`Python/cases/hyper5/` Demo 4.7): `Hyper5` (`type="HYPER5"`, health=1; aero required, prop if `mprop!=0`) plus registered `TARGET3` / `SATELLITE3` (no decks). HYPER6 is runnable from JSONC (`Python/cases/hyper6/` climb): `Hyper6` (`type="HYPER6"`, health=1; both aero and prop decks required). Radar/Satellite/Ground0 are not registered. Colliding CADAC type tokens bind via `VehicleSpec.family` (source of truth; scenario-level `"family"` is a load-time default; `RunConfig` has no family field). Family set → `_VEHICLE_FAMILIES[(family, type)]` only, no fallthrough; omitted → `_VEHICLE_TYPES`. `register_family_type` is idempotent for the same class and never writes `_VEHICLE_TYPES`. Map starts empty (no AIM5/SAM6 pairs yet). Translate `family=` stamps each vehicle; `SAM_DECK`/`SRBM_DECK` → `sam_deck`/`srmb_deck`; bare `ENDIF` skipped. E2E `tests/e2e/test_hyper5_pronav.py` skips if `tests/e2e/goldens/hyper5/plot.csv` is absent. HYPER5 Python modules: aero (Roadrunner 3X), propulsion (mprop 0–3), forces (FSPV), control (`control_bank`, `control_load`, `control_altitude`, `control_heading`, `control_flightpath`, `control_lateral`, `mcontrol` in `{0,3,4,6,16,36,40,44}`), guidance (`guidance_point`, `guidance_pronav`, `guidance_arc`; `mguidance` in `{0,44,66,70}`), seeker (`mseeker` in `{0,1,3}`; Demo 4.7 `acq_range=6000`), intercept (`halt` / ground `alt<=0` / seeker closest-approach; `vehicle.health=0` and combus status 0; no `sys.exit`), targeting (`mtargeting==0` return; `==1` satellite visibility / closest TARGET3 waypoint; else ValueError), `Target3` (`type="TARGET3"`; Round3 env+newton + Target Coriolis/centrifugal forces + intercept `targ_health` from combus; constructor `(name, events=None)`, no decks), and `Satellite3` (`type="SATELLITE3"`; Round3 env/newton + `Satellite3Forces`; `sat_thrust` default 0, `sat_mass` default 100; `FSPV=[sat_thrust/sat_mass,0,0]`; constructor `(name, events=None)`, no decks, no seeker). Round3 ISO 62 later. Seven EOM layers in the spec; MAGSIX Rotor is not Flat6. SAM6 Flat0 (`cadac.eom.flat0`): launch clock (`time`/`launch_delay`/`launch_epoch`/`launch_time`) and fixed-site newton (`srel1/2/3` → `SREL`). SAM6 Flat3 (`cadac.vehicles.sam6.flat3`, not `cadac.eom.flat3`): `SAEL`/`VAEL`/`dvae`/`FSPA`/`TAL`/`TAV`/`TVL`; env `atmosphere76(-SAEL[2])` and `mach` from `dvae`; newton `NEXT_ACC = TAL.T @ FSPA + (0,0,grav)`; kinematics launch clocks as C++. SAM6 missile aero (`cadac.vehicles.sam6.aero.Sam6Aero`): Datadeck constructor; C++ `def_aerodynamics` (`refl=0.25`, `refa=0.0491`); execute tables then `aerodynamics_der`; store `vmach` as C++ `mach`; `mprop==0` adds `cab`. SAM6 missile propulsion (`cadac.vehicles.sam6.propulsion.Sam6Propulsion`): Datadeck constructor; tables vs `msl_time`; `thrust=look_up("thrust_vs_time",msl_time)+(101325-press)*aexit` (`aexit` default 0.0314); `mass`/`xcg`/`ai33`/`ai11` from tables; `mprop=1` if `msl_time<=60` else 0; skip `mfreeze` if absent. SAM6 missile forces (`cadac.vehicles.sam6.forces.Sam6Forces`): define `FAPB`/`FMB`; C++ aero sums; `mtvc==0` adds `thrust` to `FAPB[0]`; `mtvc!=0` ValueError (no `FPB`/`FMPB`); missing `FARCS`/`FMRCS` as 0; does not write newton `FSPB`. SAM6 missile actuator (`cadac.vehicles.sam6.actuator.Sam6Actuator`): port of SAM6 `actuator.cpp`/`actuator_scnd`; local CADAC sign; `mact<2` position-limit (includes 1); `mact==2` second-order; else ValueError; cross-fin mix and `dpx`/`dqx`/`drx` as C++. SAM6 missile control (`cadac.vehicles.sam6.control.Sam6Control`): C++ `def_control`; `maut==0` return; `maut>=1` `control_roll`; `maut==2` `control_rate`; `maut==3` `control_accel` (`ancomx+=ancomx_test`, poles `zacl=0.7*(1+zacl_bias)`, `wacl=|realq1|*(1+wacl_bias)`, `pacl=(|realq2|+35)*(1+pacl_bias)`, stored-slope `zz`/`yy`); `maut==4` ValueError; skip `factwacl`/`twcl` if absent; INS `WBECB`/`FSPCB`/`thtblcx`/`phiblcx`; `SMALL` on `|dmd|` as C++ (not `dld`); local CADAC sign. SAM6 missile INS (`cadac.vehicles.sam6.ins.Sam6Ins`): port of SAM6 `ins.cpp`; `mins==0` copies `TBL`/`FSPB`/`WBEB`/`SBEL`/`VBEL`/`dvbe` then Euler/FPA; `mins==1` error ODEs with `gauss`/`uniform` 0 (Cholesky `XX_INIT` 0, `EWALKA=0`); else ValueError; `ins_alt` with `biasal=randal=0`. SAM6 missile guidance (`cadac.vehicles.sam6.guidance.Sam6Guidance`): decode `guid_mid=mguide//10`, `guid_term=mguide%10`; mid 2 line to IP from `RADAR0` `SIEL{k+1}` minus `SBELC` (k-th `MISSILE6`); term 6/7 compensated/RF pronav as C++; mid 3 `ValueError`; circular limiter vs `gmax` always (mguide=0 writes zero commands). SAM6 missile sensor (`cadac.vehicles.sam6.sensor.Sam6Sensor`): port of SAM6 `sensor.cpp`; `mseek==0` return; `mtarget==1` `ROCKET5` / `==2` `AIRCRAFT3` else ValueError; k-th `MISSILE6` → k-th target of that type (`Packet.type`); read `SAEL`/`VAEL` by name; RF `skr_type==1` mode 2 acquire `dbtk<racq_rf` → 3 then 4 lock as C++; IR `skr_type==2` as C++; `skr_dyn==1` with bias/random/glint/MARKOV 0; other `skr_type` ValueError. SAM6 missile intercept (`cadac.vehicles.sam6.intercept.Sam6Intercept`): no `sys.exit`/`print`; `stop&&trcond` → `vehicle.health=0` and combus status 0; ground `alt<=0` or `hbe<=0` with `write` latch; IP `ip_sltrange<500` closing-speed as C++; `skr_mode==4` and `dbt<500` closest-approach `mterm` 0/1 kills missile and `tgt_slot` packet; `mterm==2` ValueError. SAM6 missile TVC (`cadac.vehicles.sam6.tvc.Sam6Tvc`): C++ `def_tvc` including `FPB`/`FMPB`; `mtvc==0` leaves zeros; else ValueError. SAM6 missile RCS (`cadac.vehicles.sam6.rcs.Sam6Rcs`): C++ `def_rcs` including `FMRCS`/`FARCS`; `mrcs_moment==0` and `mrcs_force==0` leave zeros; else ValueError. SAM6 aircraft guidance (`cadac.vehicles.sam6.aircraft.Sam6AircraftGuidance`): port of `Aircraft::guidance`; `acft_option==0` `ACOML=(0,0,-grav)`; `==1` inside `[man_start,man_stop)` `ACOML=TVL.T@[0,gturn*grav,-grav]`; `==2` escape vs first `MISSILE6` `SBEL`/`VBEL` by `Packet.type`; outside window gravity bias; else ValueError. SAM6 aircraft control (`Sam6AircraftControl`, `name="control"`): port of `Aircraft::control`; bank from `TVL@ACOML`; `tphi==0` no lag; limit `philimx`; write `phiavout`; load-factor lag `tanx`; `acft_option>0` alpha limiter `pdynmc*clalpha*alplimx/wingloading`; local CADAC sign. SAM6 aircraft forces (`Sam6AircraftForces`, `name="forces"`): port of `Aircraft::forces`; `FSPA=(acc_longx*grav, 0, -anx*grav)`; does not define Flat3/control names (`grav`/`anx`). No `Sam6Aircraft` vehicle. SAM6 rocket aero (`cadac.vehicles.sam6.rocket.Sam6RocketAero`): Datadeck constructor (`SRBM_aero_deck`); look_up `cltgt_vs_alpha_mach`/`cdtgt_vs_alpha_mach`; body `catgt`/`cntgt`/`cytgt`; `mprop==0` `catgt*=1.1`; init `cnalp=7.468`. SAM6 rocket propulsion (`Sam6RocketPropulsion`): analytic SRBM1; `mprop==1` mass flow `thrust_sl/(isp*9.81)`, `mass=mass_launch-mass_flow*launch_time`, `thrust=thrust_sl+(pres_sl-press)*aexit`, burnout `mprop=0`; `mprop` not in `{0,1}` ValueError; defaults `mass_launch=6000`, `mass_fuel=4000`, `isp=230`, `thrust_sl=128600`, `aexit=0.282`. SAM6 rocket sensor (`Sam6RocketSensor`, `name="sensor"`): port of `Rocket::sensor`; `mseek==0` no-op; `mseek!=0` and `flag_exo` and `alt<alt_endo` kinematic LOS to `stel1/2/3`; conditions off no-op as C++ if-block skip. SAM6 rocket guidance (`Sam6RocketGuidance`, `name="guidance"`): port of `Rocket::guidance`; `mguide==0` circular limiter of zeros → `ancomx==0`,`alcomx==0`; `guid_mode==1` pronav; `guid_manvr==1` spiral as C++ (OR-phi limiter); decoded fields not in `{0,1}` `ValueError`. SAM6 rocket control (`Sam6RocketControl`, `name="control"`): port of `Rocket::control`; `maut==0` ballistic (no accel loop); `maut==1` and `alt<alt_endo` P-I as C++ (`tr`, `gacp`, `ta=2.2`); exo sets `flag_exo` and zeros states; ascent `ancomx_bias` while `not flag_exo`; else ValueError. No `Sam6Rocket` vehicle. Protocol `vehicle.store`. No Flat6/Plane imports. SAM6 missile euler (`cadac.vehicles.sam6.euler.Sam6Euler`): port of SAM6 `euler.cpp` (not Flat6Euler); states `ppd/pp`,`qqd/qq`,`rrd/rr`; `ppd_new=FMB[0]/ai11`; `qqd_new=((ai33-ai11)*pp*rr+FMB[1])/ai33`; `rrd_new=(-(ai33-ai11)*pp*qq+FMB[2])/ai33`; writes `WBEB`,`ppx`,`qqx`,`rrx`.
